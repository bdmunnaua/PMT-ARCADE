What the contract can and cannot do

  • Fixed supply. All 10,000,000,000 PMT were created once, when the contract was deployed. There is no mint function, so no one can ever create more.
  • No owner and no admin keys. The contract has no owner, pause, blacklist or upgrade functions. Nobody can freeze or take PMT from a wallet.
  • No tax. Transfers pay no buy, sell or transfer tax inside the contract.
  • Standard, verified code. It is the standard OpenZeppelin ERC-20, and its source code is verified on BscScan (exact match, Solidity 0.8.34).

Check it yourself: contract source code on BscScan.

Where PMT is today

PMT is not listed on any exchange and does not have an established DEX market price yet. Liquidity is planned for a later phase. It is used inside PMT Arcade. Your PMT balance on the site is kept by the platform. When withdrawals are open, you can move PMT to your own wallet on BNB Smart Chain.

All PMT not yet given out is held in the wallet that created the contract: 0xe328A50732109d129BCf9B302Cfe362949F77FB4. Shares will be moved to separate public wallets as described in the whitepaper. All project wallets are listed with live balances on the transparency page.

Add PMT by hand

  1. In MetaMask, switch to BNB Smart Chain.
  2. Tap Import tokens and paste the contract address above.
  3. The symbol (PMT) and decimals (18) fill in automatically. Confirm.
